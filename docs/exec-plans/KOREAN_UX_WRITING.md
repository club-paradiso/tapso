# 한국어 UX 라이팅 정리

## 목표와 범위
메인 소개에서 요청한 두 문구를 제거하고, 버스 정보 지연·개인정보·후원·FAQ의 어색한 비유와 반복을 실제 동작 중심의 해요체로 정리한다. 캠페인 문구, 디자인, 앱 화면의 실제 문자열, 후원 경로와 결제 로직은 유지한다.

## 확인한 기준
https://oaiwan.kr/g/ux-writing 원문과 제공 ZIP의 SKILL.md, 한국어 표현·모빌리티·기기 권한·결제 참고 파일을 읽었다. 같은 개념에 같은 용어를 쓰고, 반복은 줄이되 선택 조건과 제약은 남긴다. 개발 중·TestFlight 미공개·수동 차량 확인·실제 iPhone 검증 전·백그라운드 미검증은 계속 알린다.

## 결정
- 메인 설명은 제품 가치로 끝내고 개발 상태는 한 줄로 분리한다.
- 신뢰 설명은 의인화 대신 지연 표시, 마지막 확인 값, 알림 중단과 재개를 설명한다.
- 개인정보는 버스 위치 데이터로 계산하는 이유를 먼저 쓰고 선택 기능 권한과 검증 범위는 함께 안내한다.
- 후원 창 제목은 ‘계좌이체로 응원하기’, ‘커피 한 잔 값으로 응원하기’로 바꾼다. 송금 전 확인, 수취 정보와 세금 안내는 보존한다.

## 검증 및 진행
문구 편집 및 로컬 시각 확인 완료. 320px·390px 모바일과 1440px 데스크톱에서 줄바꿈·가로 넘침·기존 상세 사용 과정을 확인했고, 테마 전환도 확인했다. 웹 테스트는 200개 통과했다. 예전 문구를 고정한 테스트는 새 문구에 맞추되 출시·권한·실기기 검증 경계 검사와 등록 폼 미노출 검사는 유지했다. 최종 타입 검사와 클라이언트·SSR 프로덕션 빌드도 통과했다. 다음: PR 및 CI 통과 후 병합, 운영 READY와 실제 문구 확인. 실제 iPhone 검증은 이 작업 범위에 포함하지 않는다.
