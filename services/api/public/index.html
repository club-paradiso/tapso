TAPSO Transit API

Server-side boundary between TAPSO clients and the official TAGO bus route and location services. This host serves JSON only; the TAPSO product site lives elsewhere.

  • GET /health
  • GET /v1/cities
  • GET /v1/routes?cityCode=&routeNo=
  • GET /v1/stops?routeId=&cityCode=
  • GET /v1/vehicles?routeId=&cityCode=

Live vehicle snapshots carry no source observation timestamp, so automatic vehicle matching stays withheld and freshness-dependent behavior fails closed.
